# 运行与交付说明

## 1. 环境要求

- Windows 10/11
- Python 3.9+，推荐 3.11
- Node.js 18+
- 后端虚拟环境：`backend/venv/`

## 2. 环境变量

复制并编辑：

```text
backend/.env.example → backend/.env
```

可配置 Provider：

```text
SPARK_API_KEY
DEEPSEEK_API_KEY
BIGMODEL_API_KEY
OPENAI_API_KEY
MIMO_API_KEY
DEFAULT_LLM_PROVIDER
```

不要把真实 API Key 提交到 Git。未配置的 Provider 会被降级链自动跳过。

## 3. Windows 启动

后端终端：

```bash
cd backend
venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

前端终端：

```bash
cd frontend
npm install
npm run dev -- --host 0.0.0.0 --port 5173
```

访问：

```text
前端：http://localhost:5173/
后端：http://localhost:8000/
API 文档：http://localhost:8000/docs
健康检查：http://localhost:8000/health
```

如果端口已被占用，先结束旧的 Node/Python 服务，再重新启动；不要同时打开多个 Vite 服务。

## 4. 验证命令

```bash
cd frontend
npm run build
```

后端专项验证：

```bash
cd backend
venv\Scripts\python.exe -X utf8 scripts/verify_ai_algorithms.py
venv\Scripts\python.exe -X utf8 scripts/verify_aic_features.py
venv\Scripts\python.exe -X utf8 scripts/verify_dataflow.py
venv\Scripts\python.exe -X utf8 scripts/verify_agent_llm.py
```

需要运行服务的验证脚本：

```bash
venv\Scripts\python.exe -X utf8 scripts/verify_live.py
venv\Scripts\python.exe -X utf8 scripts/verify_all_routes.py
```

前端 E2E：

```bash
cd frontend
npx playwright test e2e/aic-features.spec.ts --reporter=list
npx playwright test e2e/frontend.spec.ts --reporter=list
```

## 5. 数据库

默认使用：

```text
backend/ai_learning_v2.db
```

启动时会创建缺失表，但字段变更应通过 Alembic 迁移处理。运行数据库可能包含演示数据，不要在未备份的情况下重置或删除。

## 6. Docker 状态

当前仓库有 `Dockerfile` 和 `nginx.conf`，但没有根目录 `docker-compose.yml`。因此当前不提供未经验证的 Compose 启动命令；优先使用本地前后端启动方式。

## 7. 交付前检查

- 前端构建通过。
- 后端健康检查通过。
- 关键验证脚本通过。
- API Key 未被提交。
- 文档、PPT、视频和源码版本一致。
- 真实试点数据与演示数据明确区分。
