## 2. 已验证功能

- **五层算法闭环接线**：IRT θ 掌握度（小样本自动采用 1PL）、IRT b 学习成本、BKT 掌握度（按学生时间留出评估并对照基线）、GKT 图卷积传播、FSRS 记忆小节、MAB 路径调整策略/每日选题/匹配探索层（含收益闭环回传）。
- 趋势权重学习器训练（`POST /algorithms/trend/train`）与掉队预警概率输出；GKT 自监督训练（`POST /algorithms/gkt/train`）。
- RK4 暂态分析：电容充放电/电感电流波形，数值对照解析解通过。
- Dashboard、课程知识列表、每日练习核心接口。
- 多模型 Provider 注册和无 Key 跳过逻辑。
- 功能使用频率统计及学生/教师权限隔离。
- 课程元数据、跨课程依赖、跨学科路径和 DAG 无环。
- 实验行为上报和统计权限。
- 电路故障诊断及普通电路分析。
- 学习行为、测验、画像、路径、趋势、教师报告数据流。
- Agent 反思、缓存、JSON 容错、降级和防幻觉守卫。
- 教师设置页通知偏好持久化、缓存清理、退出登录，以及需校验当前密码的密码修改链路。

## 3. 已实现但依赖运行环境

- 真实 LLM 调用：需要至少一个有效 Provider API Key。
- DeepSeek、智谱、OpenAI、MiMo：需要对应 Key，未配置时不会实际调用。
- WebSocket 辅导：需要后端服务和有效 Token。
- OCR、PPT、生图：需要对应服务配置或素材服务可用。
- 前端页面交互：需要浏览器、前后端服务和数据库状态一致。
