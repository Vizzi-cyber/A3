# LearnLab AIC 技术方案摘要

## 1. 系统分层

```text
前端展示层（React + TypeScript）
        ↓ REST API / WebSocket
业务应用层（学习闭环、教师端、实验实训、试点报告）
        ↓
算法层（ADPP、BKT、IRT、FSRS、Thompson Sampling、12 Agent）
        ↓
数据层（知识点、课程元数据、学习记录、测验、画像、实验日志、趋势）
        ↓
大模型接入层（星火、DeepSeek、智谱、OpenAI、MiMo）
```

## 2. 多智能体

平台包含 12 个教育智能体：

- 课程设计师（Supervisor）
- 画像师
- 路径规划师
- 资源生成师
- 辅导助手
- 知识图谱构建师
- 思维溯源师
- 错误捕捉师
- 项目拆解师
- 角色匹配师
- 协作督导
- 成果评估师

Agent 通过标准消息协议和 LangGraph StateGraph 协作，支持条件路由、并行 fan-out、反思循环和缓存。

## 3. 自适应路径与学习算法

### ADPP

```text
知识点 DAG → 拓扑排序 → 关键度计算 → 掌握度预测
→ 多因子学习成本 → 加权排序 → 阶段划分 → 个性化路径
```

### 四类算法

| 算法 | 作用 | 当前验证 |
|---|---|---|
| BKT | 知识掌握度追踪 | 23 项算法专项验证通过 |
| IRT | 学生能力与题目难度诊断 | 23 项算法专项验证通过 |
| FSRS | 间隔重复与复习队列 | 23 项算法专项验证通过 |
| Thompson Sampling | 自适应选题 | 23 项算法专项验证通过 |

## 4. 跨学科数据链路

- `courses` 保存三门课程的学科元数据。
- 知识点支持跨课程 prerequisites。
- 已注入跨课程依赖并验证无环。
- `/learning-path/courses` 提供课程元数据。
- `/learning-path/cross-discipline` 提供跨学科路径。
- 前端学习路径页提供跨学科链路展示。

## 5. 虚拟实验与 AI 诊断

- 浏览器端 MNA 电路求解器：并查集、矩阵构建、部分主元高斯消元。
- 电路故障实验：断路、短路、错值元件等模板。
- 本地规则即时判断 + AI 诊断评估。
- STM32 实验实训：实验目标、元件、步骤、完成度和实验报告。
- 实验行为写入 `experiment_logs`，供教师试点分析使用。

## 6. 可靠性与安全

- 多 Provider 注册和 FailoverLLM 自动降级。
- 未配置 API Key 的 Provider 自动跳过。
- 输入安全过滤、Prompt 约束、输出结构校验。
- Python 代码 AST 校验和引用溯源检查。
- 低质量输出可触发 LLM 自我纠错。
- 电路分析和知识图谱构建具备业务降级路径。

## 7. 试点数据闭环

```text
学习行为 + 测验 + 画像 + 实验行为 + 功能使用
    → 学生/班级统计 → 前后测对比 → 试点报告 Markdown 导出
```

## 8. 事实状态

本方案中的“已完成”仅指代码和现有验证脚本已经覆盖的能力，不代表真实学生试点、最终竞赛材料或所有 Provider 已在当前环境配置并运行。
