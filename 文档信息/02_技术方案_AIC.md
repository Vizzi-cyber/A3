# LearnLab AIC 技术方案摘要

## 1. 系统分层

```text
前端展示层（React + TypeScript）
        ↓ REST API / WebSocket
业务应用层（学习闭环、教师端、实验实训、试点报告）
        ↓
算法层（ADPP、BKT、IRT、FSRS、Thompson Sampling、12 Agent）
        ↓
数据层（知识点、课程元数据、学习记录、测验、画像、实验日志、趋势）
        ↓
大模型接入层（星火、DeepSeek、智谱、OpenAI、MiMo）
```

## 2. 多智能体

平台包含 12 个教育智能体：

- 课程设计师（Supervisor）
- 画像师
- 路径规划师
- 资源生成师
- 辅导助手
- 知识图谱构建师
- 思维溯源师
- 错误捕捉师
- 项目拆解师
- 角色匹配师
- 协作督导
- 成果评估师

Agent 通过标准消息协议和 LangGraph StateGraph 协作，支持条件路由、并行 fan-out、反思循环和缓存。

## 3. 自适应路径与学习算法

### ADPP

```text
知识点 DAG → 拓扑排序 → 关键度计算 → 掌握度预测
→ 多因子学习成本 → 加权排序 → 阶段划分 → 个性化路径
```

### 五层算法闭环

| 层 | 算法 | 作用 | 当前验证 |
|---|---|---|---|
| 测量 | IRT（1PL/2PL MAP 联合估计） | 能力 θ 替代加权平均分、难度 b 替代人工分级 | 77 项算法专项验证通过 |
| 建模 | BKT（pyBKT EM 估计） | 逐知识点掌握概率（演示库 AUC 0.837） | 77 项算法专项验证通过 |
| 建模 | GKT（可学习门控图卷积） | 邻居知识点掌握度传播，自监督训练 | 77 项算法专项验证通过 |
| 记忆 | FSRS | 间隔重复复习队列与可提取性预警 | 77 项算法专项验证通过 |
| 决策 | Thompson Sampling | 路径调整策略 / 每日选题 / 匹配探索层 | 77 项算法专项验证通过 |

另有 NCD 神经认知诊断（numpy 单调约束）、趋势权重学习器（L2 逻辑回归掉队预警）、多维加权匹配（先验打分 + MAB 探索层）均纳入验证。全部算法已接线进业务链路：dashboard 掌握度（IRT θ 百分位）、路径学习成本（IRT b）、路径调整与选题（MAB）、趋势报告（学习权重 + 预警概率）、资源匹配（探索层 + 收益反馈闭环）。

## 4. 跨学科数据链路

- `courses` 保存三门课程的学科元数据。
- 知识点支持跨课程 prerequisites。
- 已注入跨课程依赖并验证无环。
- `/learning-path/courses` 提供课程元数据。
- `/learning-path/cross-discipline` 提供跨学科路径。
- 前端学习路径页提供跨学科链路展示。

## 5. 虚拟实验与 AI 诊断

- 浏览器端 MNA 电路求解器：并查集、矩阵构建、部分主元高斯消元（直流稳态，电感按短路正确处理）。
- RK4 暂态分析：电容/电感状态变量法 + 四阶 Runge-Kutta，输出充放电波形与稳态建立时间；RC/RL/LC 数值对照教科书解析解（9/9 通过）。
- 电路故障实验：断路、短路、错值元件等模板。
- 本地规则即时判断 + AI 诊断评估。
- STM32 实验实训：实验目标、元件、步骤、完成度和实验报告。
- 实验行为写入 `experiment_logs`，供教师试点分析使用。

## 6. 可靠性与安全

- 多 Provider 注册和 FailoverLLM 自动降级。
- 未配置 API Key 的 Provider 自动跳过。
- 输入安全过滤、Prompt 约束、输出结构校验。
- Python 代码 AST 校验和引用溯源检查。
- 低质量输出可触发 LLM 自我纠错。
- 电路分析和知识图谱构建具备业务降级路径。

## 7. 试点数据闭环

```text
学习行为 + 测验 + 画像 + 实验行为 + 功能使用
    → 学生/班级统计 → 前后测对比 → 试点报告 Markdown 导出
```
