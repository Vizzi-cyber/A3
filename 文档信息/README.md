## 使用规则

1. 先查主文档，再查原始材料；历史结论查 `归档/`。
2. 功能状态以 `03_功能与验证报告.md` 和实际验证命令为准。
3. 比赛待办与截止时间以 `04_比赛材料准备清单.md` 为准。
4. 启动和交付以 `05_运行与交付说明.md` 为准。
5. 未配置 API Key、未开展试点和未完成的视频/PPT，不写成已完成事实。
