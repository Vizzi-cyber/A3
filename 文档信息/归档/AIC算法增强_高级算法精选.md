## 1. S 级：顶会前沿阵容（评审眼里最亮）

### 1.1 Thinking-KT —— 测试时缩放知识追踪 ⭐ 2026 最前沿

**是什么**：把大模型圈的 **Test-Time Scaling（推理时思考/测试时计算）** 引入知识追踪：训练免微调的小 LLM 框架，作答时"多想几步"，一次性输出 **预测 + 个性化反馈 + 学习推荐**（unified prediction & prescription）。

**高级感在哪**：三大热词叠加——Test-Time Scaling（o1/DeepSeek-R1 式推理时扩展）、LLM 知识追踪、预测-处方一体化。2026 年 1 月的论文，比绝大多数参赛作品领先一个身位。

**在 LearnLab 的应用**：
- `tutor.py` 苏格拉底辅导：思考链式推理 → 输出"掌握度预测 + 个性化反馈 + 下一资源推荐"三合一
- 免微调、免训练，直接接现有 LLMFactory，数据需求小
- 叙事："我们从'一次调用出答案'升级为'测试时深度思考，预测-反馈-推荐一体输出'"

### 1.2 Agentic Knowledge Tracing —— 多智能体知识追踪 ⭐ 与 12Agent 完美对标

**是什么**：多智能体 LLM + BKT 的混合流水线：LLM 事件分类器 → 4 个领域专属 agent 做会话级推理 → 各能力域独立跑 BKT 模型 → **法官 agent** 合成最终掌握度。发表于 IEEE CoG 2026，预测效度约为单 LLM 基线 **3 倍**。

**高级感在哪**："Agentic"是 2025-2026 顶会最热词汇；多智能体 + 贝叶斯模型的混合架构与 LearnLab 的 12Agent 体系**同构**——直接引用可让整个架构叙事获得论文级背书。

**在 LearnLab 的应用**：
- 现有 12Agent 星型拓扑 + CourseDesigner 总控 = 论文中的"法官 agent"角色
- 每个学科域（C 语言/电路/STM32）一个专属追踪 agent + 独立 BKT 参数
- 叙事："我们的 12Agent 不是噱头——Agentic Knowledge Tracing（IEEE CoG 2026）证明多智能体 BKT 流水线的预测效度是单 LLM 的 3 倍"

### 1.3 LLM 认知诊断家族（KCD / LLM4CD / LMCD / DLLM）⭐ 大模型×测量学

**是什么**：用大模型的**开放世界语义知识**增强/替代传统认知诊断的 ID 嵌入，解决冷启动与稀疏问题。代表：
- **KCD**（arXiv:2502.05556, 2025）：大模型认知诊断，知识-概念-能力联合建模
- **LLM4CD**（arXiv:2505.13492, 2025）：LLM 驱动的认知诊断范式
- **LMCD**（arXiv:2505.21239, 2025，**好未来 TAL 开源**）：轻量大模型认知诊断，可直接部署
- **DLLM**（arXiv:2510.04093, 2025）：**扩散去噪 + LLM** 的认知诊断——扩散模型进场教育

**高级感在哪**："认知诊断"是教育测量学正统（IRT 的血脉），叠加"大模型""扩散模型"两个 2025 顶流词；LMCD 有商业公司开源，落地可信度拉满。

**在 LearnLab 的应用**：
- `profiler.py` 画像：学生能力诊断从"答题正确率"升级为"LLM 语义感知的认知诊断"
- 题目难度/区分度标定：告别人工定难度
- 冷启动场景（新生无答题数据）：靠题目文本语义直接诊断
- 叙事："画像不是问卷填出来的，是由扩散-大模型认知诊断（DLLM, arXiv:2510.04093）从语义层面推断出来的"

### 1.4 Responsible-DKT —— 神经符号知识追踪 ⭐ 可解释 + Responsible AI 双 buff

**是什么**：把**符号教育规则**（掌握/未掌握的教学逻辑）注入深度知识追踪 DKT，形成 grounded 计算图：**10% 训练数据即达 AUC > 0.80**，且提供局部+全局解释。作者含 Gašević 等教育数据挖掘领域权威。

**高级感在哪**："神经符号（Neuro-Symbolic）"+"Responsible AI（负责任 AI）"双 buff，2026 年 4 月论文；"10% 数据达到高性能"直击小样本场景痛点，评审无法忽视。

**在 LearnLab 的应用**：
- `path_planning_dag.py`：掌握度预测引擎，教育规则注入保证预测符合教学常识
- 可解释性 → 直接支撑"AI 赋能价值可验证"的评分要求
- 小数据友好 → 初期试点数据不足也能跑
- 叙事："我们不是黑盒——Responsible-DKT（arXiv:2604.08263）证明注入教学规则的神经符号模型 10% 数据即可达 AUC 0.80"

### 1.5 EduQate —— NeurIPS 2024 网络化流失多臂老虎机 ⭐ 数学含金量最高

**是什么**：提出 **EdNetRMABs（Education Network Restless Multi-armed Bandits）**——知识点间依赖关系建模为**网络**，臂的状态随时间"流失"（restless，不行动也会衰减），用**依赖感知 Q-learning** 选臂（选题），**带最优性证明**。NeurIPS 2024。

**高级感在哪**：NeurIPS 正会 + Restless MAB（流失臂）+ 网络建模 + 最优性证明——数学味最浓的选项，评审里搞算法的一眼认可。

**在 LearnLab 的应用**：
- `daily_quiz.py` 选题：从固定规则 → 网络化流失臂决策（知识点依赖即网络边）
- 与 ADPP 融合：路径规划 = 知识点网络上的 restless bandit 问题
- 叙事："选题不是随机也不是贪心——我们把知识点依赖建模成网络，用带最优性证明的 Restless MAB（NeurIPS 2024）求解"

## 2. A 级：经典响亮阵容（名字就值钱）

### 2.1 RAG-KT —— 检索增强知识追踪

**是什么**：把知识追踪当作"受可靠上下文约束的 LLM 推理"：Question Group 抽象对齐多源数据、检索互补上下文做 grounded 预测，解决分布漂移与冷启动。同方向：TutorLLM（arXiv:2502.15709）。

**高级感**：RAG 是当下最热的工程范式，加上"跨平台""grounded 推理"词汇，观感直接拉满。

**在 LearnLab 的应用**：知识库 + 知识图谱做检索源，跨学科内容库（C/电路/STM32）的掌握度预测统一由 RAG 增强——正好用上现有 WikiLink 知识库。

### 2.2 AKT —— 上下文感知注意力知识追踪（KDD 2020）

**是什么**：**单调注意力**（指数衰减 + 上下文感知距离）+ **Rasch 模型正则化**嵌入，兼顾精度与可解释，AUC 提升最高 6%。

**高级感**："注意力机制 + Rasch 测量学"跨界融合，KDD 正会。

**在 LearnLab 的应用**：学情趋势预测、长答题序列建模；与 LLM 诊断互补（AKT 管序列精度，LLM 管语义解释）。

### 2.3 SAINT+ —— Transformer 知识追踪（LAK 2021）

**是什么**：纯 Transformer **Encoder-Decoder** 架构：编码器吃习题流、解码器吃作答流，嵌入 **elapsed time（作答耗时）与 lag time（间隔时长）** 显式建模遗忘——在 EdNet 教育最大公开数据集上 SOTA。

**高级感**："Transformer + 遗忘建模 + 最大数据集 SOTA"三连。

**在 LearnLab 的应用**：作答耗时/间隔数据已由学习记录采集，直接喂 SAINT+ 建遗忘感知的掌握度模型。

### 2.4 NCD —— 神经认知诊断（AAAI 2020）

**是什么**：学生/习题因子向量 + 多层神经网络拟合交互，**单调性约束**保证可解释——IRT 的神经网络版（中科大团队）。

**高级感**：AAAI 正会，"神经 + 测量学约束"。

**在 LearnLab 的应用**：画像诊断的轻量可解释引擎，输出每知识点掌握度，直接喂 ADPP 六因子模型。

## 3. B 级：认知科学味道（偏学术、工程性稍弱）

### 3.1 SM-17 双组分记忆模型（SuperMemo 17, 2024）

**是什么**：用**可提取性（Retrievability）+ 稳定性（Stability）**双组分描述记忆，神经网络预测遗忘曲线，调度最优复习时刻。SuperMemo 17 于 2024 年发布。

**在 LearnLab 的应用**：复习调度引擎，替代现在只有提示语的"艾宾浩斯提醒"。

### 3.2 ACT-R 认知架构激活衰减（Anderson & Lebiere 1998）

**是什么**：认知科学旗舰架构 ACT-R 的声明性记忆理论：记忆激活 A = B + ΣWᵢSⱼᵢ − d·ln(T)，随间隔**对数衰减**，低于阈值即遗忘。

**在 LearnLab 的应用**：记忆保持的理论基底，与复习调度结合做"遗忘预警"。

### 3.3 GKT —— 图知识追踪（IEEE/WIC/ACM WI 2019）

**是什么**：知识点依赖建图，**GCN + GRU** 每步聚合邻居掌握度更新学生状态——图神经网络进入教育。

**在 LearnLab 的应用**：现有知识点 DAG 就是现成的图，GKT 在图上传播掌握度，比独立知识点建模更准。

## 4. 组合叙事：把高级算法拼成"顶会级"架构

```
┌──────────────────────────────────────────────────────────────────────┐
│  【诊断层】LLM 认知诊断 KCD/LMCD + NCD                                 │

└──────────────────────────────┬───────────────────────────────────────┘
                               ▼
┌──────────────────────────────────────────────────────────────────────┐
│  【追踪层】Agentic KT（多智能体 BKT 流水线）                           │
│           + Responsible-DKT（神经符号，教育规则注入，10% 数据 0.80）   │
│  12Agent 即论文中的多智能体编排，CourseDesigner 即法官 agent           │
└──────────────────────────────┬───────────────────────────────────────┘
                               ▼
┌──────────────────────────────────────────────────────────────────────┐
│  【记忆层】SM-17 双组分记忆 + ACT-R 激活衰减                          │
│  可提取性 R + 稳定性 S → 遗忘预警与最优复习时刻                       │
└──────────────────────────────┬───────────────────────────────────────┘
                               ▼
┌──────────────────────────────────────────────────────────────────────┐
│  【决策层】EduQate 网络化 Restless MAB（NeurIPS 2024）                │
│  知识点网络上的依赖感知 Q-learning 选题，带最优性证明                 │
└──────────────────────────────┬───────────────────────────────────────┘
                               ▼
┌──────────────────────────────────────────────────────────────────────┐
│  【推理层】Thinking-KT 测试时缩放                                      │
│  预测 + 个性化反馈 + 学习推荐三合一，一次输出                         │
└──────────────────────────────┬───────────────────────────────────────┘
                               ▼
┌──────────────────────────────────────────────────────────────────────┐
│  【增强层】RAG-KT 检索增强（跨学科内容库 / WikiLink 知识图谱）         │
└──────────────────────────────────────────────────────────────────────┘
```

**一句话叙事**："LearnLab 不是通用 AI 套壳，而是由 **LLM 认知诊断（KCD/LMCD）** 测量、**多智能体+神经符号知识追踪（Agentic KT / Responsible-DKT）** 建模、**双组分记忆（SM-17）** 调度、**网络化流失老虎机（EduQate, NeurIPS 2024）** 决策、**测试时缩放（Thinking-KT）** 推理的教育算法系统——每一个模块都有顶会级出处。"

## 6. 实施路线（高级版，务实兜底）

| 阶段 | 内容 | 数据需求 | 说明 |
|------|------|---------|------|
| 第 1 批 | **NCD**（AAAI 2020）+ **SM-17 双组分记忆** | 小 | 经典可解释、好落地，先把"认知诊断+记忆调度"两个词做实 |
| 第 2 批 | **Responsible-DKT**（神经符号）+ **RAG-KT**（检索增强） | 小~中 | 10% 数据即高性能 + 知识库检索，评审演示强 |
| 第 3 批 | **Agentic KT**（多智能体 BKT 流水线） | 中 | 与现有 12Agent 同构，改动最小、叙事最响 |
| 第 4 批 | **LMCD**（好未来开源）+ **Thinking-KT**（测试时缩放） | 中 | 大模型认知诊断 + 2026 最前沿叙事 |
| 收尾 | **EduQate**（NeurIPS 2024）选题替换固定规则 | 中 | 数学含金量最高的收尾亮点 |

> **务实提醒**：SAINT+/DKT 这类需要万级答题数据的深度模型，初期数据不够时先写进"展望/数据规模规划"，别在方案里承诺已实现——**"文档与代码一致"的诚信原则比任何算法都重要**（这也是你们挑战赛优化文档里强调的）。

## 7. 一句话总结

**评审眼里最亮的前三名**：🧠 **Thinking-KT**（测试时缩放，2026 最前沿）→ 🤖 **Agentic KT**（多智能体，与 12Agent 同构）→ 📐 **EduQate**（NeurIPS + 最优性证明，数学味最浓）。

**性价比最高组合**：**LMCD（开源）** + **Responsible-DKT（小数据）** + **Thinking-KT（免训练）**——三者都主打"小数据 + 可解释 + 前沿概念"，竞赛评审性价比拉满。
