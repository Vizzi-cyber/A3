# LearnLab 答辩汇报脚本（4:50）

## 一、开场：问题与定位（0:00 – 0:25）

画面操作：打开平台首页 → 点击右上角「开始学习」进入登录页 → 点击「体验学生账号」按钮（登录卡片底部左侧，蓝色边框）→ 进入学习仪表盘。

旁白：

先讲我们解决什么问题。新工科的 C 语言、电路分析、STM32 三门课，学生基础参差却共用一份教案；实验室排队两小时、上手十分钟；三门课各教各的，知识链是断的。传统 LMS 只能把资料挂上网，做不到按认知状态规划学习顺序、在黄金纠错期即时答疑、把上百名学生的薄弱点算出趋势。

LearnLab 用一套五层教育算法闭环来解：测量、建模、记忆、决策、解释。每一层都有经典文献出处，实现全部自研，并且真正接进了业务链路。

## 二、学习仪表盘（0:25 – 0:45）

画面操作：光标移到上方四张卡片（本周学习 / 连续打卡 / 掌握知识点 / 待完成任务）；滚轮下移到「知识掌握进度」环形图，再下移到右下方日历（可见连续打卡的绿色标记）。

旁白：

登录进来是仪表盘。这四张卡片的数据都来自学习行为表实时统计——本周学习时长、连续打卡天数、已掌握知识点数。右边日历上的绿色日期，就是这个学生的连续学习记录。下方环形图是知识掌握进度，35 个知识点里已掌握多少个，一目了然。所有数字来自系统埋点，不是写死的。

## 三、智能辅导（0:45 – 1:10）

画面操作：点左侧「智能辅导」→ 在底部输入框输入「指针和数组有什么区别」→ 点发送 → 等回复时，光标移到右上角三个 Agent 阶段标签（Planner / Worker / Critic）。

旁白：

智能辅导。它的特点是不给答案——你问指针和数组的区别，它反问你，一步步带着你自己想通，这是苏格拉底式引导。这条消息发出去，后台是三个智能体在接力：Planner 拆任务、Worker 写回答、Critic 检查讲得对不对，右上角能看到跑到哪一步。每聊一轮，学生的画像就更新一次，后面路径规划用的就是这份画像。

## 四、学习路径（1:10 – 1:50）核心算法

画面操作：点左侧「学习路径」→ 滚轮缓慢下移，展示 SVG 依赖连线的绘制动画 → 光标停在跨学科着色的 DAG 节点上 → 点击右上角「知识依赖约束」标签 → 拖到页面下方「个性化学习资源」面板，点开「针对薄弱点」下拉。

旁白：

这条路径是自研的 ADPP 自适应 DAG 路径规划算出来的。它组合了五样东西：关键路径法确定关键知识点、BKT 掌握度给出每个点的掌握概率、IRT 难度标定的六因子成本模型估算学习时长、加权拓扑排序把薄弱环节前置、多臂老虎机做动态调整策略。

看这个例子：目标是 STM32 的 PWM 定时器。系统往前追前置依赖，一路经过 C 语言的位运算和指针，再往前是电路分析的电压波形——于是生成一条真正跨学科的学习路径。这是学科交叉最实的落点：不是把三门课的内容放一个平台，而是让学生看到知识之间的依赖。

每次测验后路径自动重排，这里用的是 Thompson Sampling——在「回炉复习、强化练习、加速推进、维持现状」四个动作里选，收益还能闭环回传。该复习的知识点，FSRS 记忆调度按遗忘曲线把它提到最前面。

下面这个面板能看到薄弱点：I2C 通信协议 37%、文件操作 40%——这些是该生各知识点的答题平均分，点「生成」就能针对薄弱点现场出资源，资源生成器的提示词里注入了前面几层算法的输出。

## 五、学习中心（1:50 – 2:15）

画面操作：点左侧「学习中心」→ 在左侧课程目录点开「第 1 章：基础理论」→ 点「1.2 电阻串联与并联」→ 右侧正文区滚轮下滑，展示讲义插图与公式 → 光标移到右栏「AI 辅导助手」。

旁白：

学习中心。左边选知识点，右边的图文讲义支持公式渲染和内联电路图。讲义、代码示例、练习题、思维导图都跟着你的薄弱点现场生成。右栏常驻 AI 辅导助手，针对当前这个知识点可以直接提问，不用跳页面。这是学生用得最多的功能。

## 六、知识冒险（2:15 – 2:30）

画面操作：点左侧「知识冒险」→ 光标依次划过闯关地图上的五个区域 → 点开一个关卡，展示题目与三档难度。

旁白：

知识冒险把练习做成闯关。五个区域从基础一路往后推进，每关三档难度。它背后也是同一套知识图谱——闯关顺序和路径规划用的是同一份依赖关系。右边还有排行榜，六个维度分别考察学习成长、连续学习、知识掌握、闯关挑战、AI 协作和进步最快，每个维度的数据都是后端按不同维度实时算出来的。

## 七、错误诊断（2:30 – 2:55）

画面操作：点左侧「错误诊断」→ 在代码框粘贴一段含错代码 → 点「捕捉错误」→ 等结果时，光标移到诊断结果的三类标签（语法 / 逻辑 / 概念）。

旁白：

错误诊断做的是分层定位。贴一段写错的代码，它先用静态分析抓语法错误，再由大模型判断逻辑，最后追到概念层——你是哪个知识点没真正理解。这一步的结果会回写画像，影响后续的资源生成和路径排序。

## 八、项目协作（2:55 – 3:10）

画面操作：点左侧「项目协作」→ 在「输入自定义项目名称」框输入「学生成绩管理系统」→ 点「智能拆解」→ 等任务树生成后，滚轮下移展示任务分解结果。

旁白：

项目协作面向小组作业。输入一个项目名，它自动拆成任务树、分配角色、跟踪进度，每个环节有专门的智能体负责。这套拆解逻辑和路径规划共用同一套知识图谱，所以拆出来的任务能对应到具体知识点。

## 九、个人空间（3:10 – 3:30）

画面操作：点左侧「个人空间」→ 滚轮下移展示学习时长统计与勋章 → 点「今日番茄钟」→ 切到右下方知识雷达图。

旁白：

个人空间汇总学习数据：时长统计、勋章徽章、专注度趋势。这里有个知识雷达图，六个维度展示能力分布，数据来自前面几层算法的输出。下面还有康奈尔笔记和费曼复盘两种反思工具，学生边学边记，笔记会自动沉淀到知识库。

## 十、知识库（3:30 – 3:45）

画面操作：点左侧「知识库」→ 点右上角「新建」按钮 → 在标题栏输入「指针与数组的区别」→ 在正文区输入 `[[` 触发双链补全提示。

旁白：

知识库支持双链。写两个中括号就能引用别的笔记，三门课的知识点最后连成一张网。这张网和前面的知识图谱是打通的——学生在笔记里建立的关联，会反过来丰富知识图谱。

## 十一、教师端（3:45 – 4:20）

画面操作：点右上角头像 → 选「退出登录」→ 回到登录页点「体验教师账号」→ 依次点左侧「首页」「学情分析」「AI 智能备课」。

旁白：

换教师账号。教师首页最值得注意的是学习预警——哪个学生状态不对劲，算法直接标出来，用的是趋势权重学习器，六个因子的权重不是人工拍的，是从历史数据学的。学情分析能看全班的薄弱点排行。后面几个都是 AI 的：备课输入主题就出完整教案；学情洞察自动写分析报告；智能组卷选好知识点和难度，一套卷子直接下发。

## 十二、收尾（4:20 – 4:50）

画面操作：切到浏览器新标签页，打开线上地址 `https://www.dreamlast.cn` → 最后停在平台 Logo。

旁白：

最后说三点。第一，五层算法全部接进真实业务链路，每一层都能产出「传统方法 vs 算法方法」的对照数据，效果可审计——BKT 的时间留出评估 AUC 是 0.9051，四项指标都优于基线。第二，跨学科不是拼盘，9 条跨课程知识关联让三门课的知识图谱真正接起来。第三，系统已在腾讯云上线运行，39 名学生注册，AI 生成类功能累计调用 600 余次、零失败；116 项算法断言、211 个接口冒烟全部通过，脚本随源码包交付，评委可以自己跑。

往后看，样本扩大后我们把单维 IRT 升级到多维认知诊断，BKT 增加遗忘因子或过渡到深度序列模型，升级路径已经预留好了。
