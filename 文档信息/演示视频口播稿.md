# LearnLab 演示视频 · 口播稿与操作脚本

> 成片目标 **4 分 40 秒**（官方限 3-5 分钟；素材多录，等待段加速）。结构：屏幕录制 + 单独口播 → 剪辑对齐 + 轻BGM。
> 时间码均为成片时间码。口播按句编号——录废了只重说那一句，剪辑时切掉废句即可。
> 讲解顺序 = 学生端侧边栏真实顺序（仪表盘 → 智能辅导 → 学习路径 → 学习中心 → 知识冒险/错误诊断）→ 教师端 → 数据收尾。

## 一、录制前检查单（开录前 10 分钟过一遍）

  ```bash
  # 终端1：后端（LearnLab 用 8001，8000 留给其他项目）
  cd backend && venv\Scripts\python.exe -m uvicorn app.main:app --port 8001
  # 终端2：前端
  cd frontend && set VITE_PROXY_TARGET=http://localhost:8001&& npx vite --port 5174
  ```

- [ ] **LLM 预热**：开录前先在智能辅导随便问一句、再点一次 AI 生成讲义——首条 LLM 响应较慢（约 8 秒），预热后现场节奏才顺

- [ ] 演示账号已登录：学生 `student_001 / 123456`（数据最丰满），教师 `T001 / Teacher123` 另开一个已登录标签页备用
