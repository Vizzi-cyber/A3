# LearnLab 答辩汇报脚本（4:50）

## 一、开场（0:00 – 0:20）

画面操作：打开 https://dreamlast.cn → 点右上角「开始学习」→ 登录页点「**体验学生账号**」。

旁白：

LearnLab 是面向新工科的跨学科 AI 学习平台，覆盖 C 语言、电路分析、STM32 三门课。它解决三个断点：资源无法匹配基础差异，路径无法解释学习顺序，反馈无法及时回到学习过程。核心是一套自研的五层教育算法引擎。

## 二、学习仪表盘（0:20 – 0:40）

画面操作：光标悬停上方四张统计卡片 → 滚轮下移到「知识掌握进度」环形图 → 再下移到右侧日历。

旁白：

仪表盘。四张卡片分别是本周学习时长、连续打卡天数、已掌握知识点、待完成任务，全部由学习行为表实时统计。右侧日历的绿色日期就是打卡记录，下方环形图展示 35 个知识点的掌握进度。所有数字都是采集所得，没有预设值。

## 三、智能辅导（0:40 – 1:05）

画面操作：点左侧「智能辅导」→ 点输入框上方的快捷按钮「**📊 薄弱诊断**」→ 等回复期间，光标移到右上角的阶段标签。

旁白：

智能辅导默认开启苏格拉底模式，不给答案，用反问逐步引导。一次提问背后是三个智能体接力：Planner 拆解任务，Worker 生成回答，Critic 核查准确性——右上角能看到执行到哪一步。对话结束后学情画像会更新，作为路径规划的输入。

## 四、学习路径（1:05 – 1:45）核心算法

画面操作：点左侧「学习路径」→ 滚轮下移，展示依赖连线绘制过程 → 光标停在跨学科着色的节点上 → 点右上角「**知识依赖约束**」标签 → 滚到右下方「AI 资源生成」面板，展开「针对薄弱点」下拉 → 点面板里的「**生成**」按钮。

旁白：

这是核心创新点，自研的 **ADPP 自适应 DAG 路径规划**。它以知识 DAG 为先修骨架，用**六因子学习成本模型**排序——输入包括先修依赖、BKT 掌握度、IRT 标定的题目难度和 FSRS 复习状态，输出随掌握度动态变化的学习顺序，不依赖固定课程目录。路径调整用多臂老虎机的 Thompson Sampling，在回炉复习、强化练习、加速推进、维持现状四个动作里选，收益闭环回传。

看这个跨学科例子：目标是 STM32 的 PWM 定时器，系统向前追溯前置依赖，经过 C 语言的位运算、指针，再到电路分析的电压波形，生成一条跨课程路径。这是学科交叉最实的落点——让学生看见知识之间的依赖，而不是把三门课堆在一个平台。

右边这个面板体现了数据的复用：它读的是刚才那条路径算出的薄弱点，点「生成」就能针对薄弱环节现场出讲义、题目或思维导图，形成「诊断—规划—资源」的闭环。

## 五、学习中心（1:45 – 2:10）

画面操作：点左侧「学习中心」→ 左侧目录点开「第 1 章：基础理论」→ 点「1.2 电阻串联与并联」→ 右栏「图文讲义」滚轮下移，展示公式与内嵌电路图。

旁白：

学习中心是三栏结构：左边课程目录和康奈尔线索栏，中间图文讲义，右边常驻 AI 辅导助手。讲义支持公式渲染和内嵌电路图，代码示例可以在浏览器里直接运行。右上角还有 OCR 拍照上传和 AI 生成 PPT 两个入口。

## 六、知识冒险（2:10 – 2:30）

画面操作：点左侧「知识冒险」→ 光标依次划过「**数组村庄**」「**栈峡谷**」「**树之森林**」「**图论迷宫**」「**动态规划神殿**」五个区域 → 滚轮下移到下方「**知识树**」→ 点右上角「**排行榜**」按钮。

旁白：

知识冒险把练习做成闯关，五个区域按知识依赖依次解锁。最下面是**知识树**——它把学习进度可视化成一棵会生长的树：树干代表等级，枝叶随掌握度展开，结出的果实对应解锁的知识点，这也是一个成长激励的设计。点进排行榜，六个维度分别考查学习成长、连续学习、知识掌握、闯关挑战、AI 协作和进步最快，每个维度由后端按不同口径实时计算。

## 七、错误诊断（2:30 – 3:00）核心创新

画面操作：点左侧「错误诊断」→ 在代码框点「**捕捉错误**」按钮 → 等结果时，光标移到「**溯源思维**」和「**错误分析**」两个按钮 → 点「溯源思维」看四层诊断链路 → 再点顶部的「**电路分析**」切换课程，展示同一入口变成电路仿真。

旁白：

错误诊断是四层溯源：从错误表象，到思维过程，再到错误模型，最后定位到根本原因，输出可执行的纠正策略，并按概念混淆型、逻辑缺失型、语法惯性错误、零基础盲区分类。

它最关键的设计是**三门课程共用同一个入口**——顶部切换课程，同一位置分别呈现 C 语言编译器报错解析、电路仿真故障分析、STM32 代码与接线协同诊断。不需要为每门课单独实现一套诊断，这是架构层面的复用。

## 八、项目协作（3:00 – 3:15）

画面操作：点左侧「项目协作」→ 在输入框输入「学生成绩管理系统」→ 点「**开始拆解项目**」按钮 → 等任务树生成后滚轮下移。

旁白：

项目协作面向小组作业。输入项目名称，系统自动拆解任务、分配角色、跟踪进度。拆解同样基于知识图谱，所以每个任务都能对应到具体知识点，不是随意切分。

## 九、个人空间（3:15 – 3:40）

画面操作：点左侧「个人空间」→ 光标移到「**画像详情**」标签页的六维雷达图 → 滚轮下移到「**遗忘曲线 · 知识点衰减**」图表 → 再下移到「**我的成就**」勋章墙 → 切换顶部「**番茄专注钟**」标签。

旁白：

个人空间是画像的中枢。这张六维雷达图展示知识基础、认知风格、学习偏好、薄弱点、学习进度和专注度，六个维度的分数都由算法计算得出。往下是遗忘曲线，红色虚线是理论记忆保留率，蓝色实线是这个学生的实际衰减，右侧列出待复习知识点和下次复习时间——数据来自 FSRS 记忆调度。再往下是勋章墙，六个成就按学习行为自动解锁。这里还有康奈尔笔记、费曼学习法和番茄钟三种学习工具。

## 十、知识库（3:40 – 4:00）

画面操作：点左侧「知识库」→ 点中栏右上角「**新建**」按钮 → 在标题栏输入「指针与数组的区别」→ 滚轮下移，光标移到右栏「**知识图谱**」标签。

旁白：

知识库是一个双向链接笔记系统。右栏的图谱用 D3 力导向布局把笔记和引用关系画出来，节点大小对应被引用次数，可以拖拽、缩放、点击跳转。

更关键的是它的自动沉淀：学生在学习中心点「标记完成」、或在学习路径提交学习反思时，后台的 Agent 会分析这段内容，提取知识点、整理成结构化 Markdown，自动归档到对应学科文件夹，并自动检测关联笔记生成双链。也就是说，学生只要正常学习，笔记是自动长出来的。

## 十一、教师端（4:00 – 4:20）

画面操作：点右上角头像 → 选「退出登录」→ 登录页点「**体验教师账号**」→ 点左侧「首页」→ 再点「学情分析」→ 再点「AI智能备课」。

旁白：

教师端首页是学习预警——状态异常的学生由趋势权重学习器标出，六个因子的权重由历史数据学习得到，样本不足时回退人工先验。学情分析看全班薄弱点分布。AI 工具承接重复劳动：智能备课输入主题生成完整教案，学情洞察自动写分析报告，智能组卷按知识点和难度直接出卷，教师预览确认后即可使用。

## 十二、收尾（4:20 – 4:50）

画面操作：切到浏览器新标签页打开 https://dreamlast.cn → 光标停在平台首页。

旁白：

三点总结。第一，五层算法全部接入真实业务链路，每一层都有可审计的对照数据——BKT 的时间留出评估 AUC 达到 0.9051，四项指标均优于基线。第二，跨学科不是拼盘：9 条跨课程知识关联接通三门课的图谱，错误诊断三门课共用一个入口，ADPP 生成真正跨课程的路径。第三，系统已在腾讯云上线运行，39 名学生注册，AI 生成类功能累计调用 600 余次零失败；116 项算法断言、211 个接口冒烟全部通过，脚本随源码包交付，可复现。

下一步，样本扩大后把单维 IRT 升级为多维认知诊断，BKT 引入遗忘因子或过渡到深度序列模型，升级路径已经预留。
