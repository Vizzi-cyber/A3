# AIC 比赛材料准备清单

## P0 必须完成

- [ ] 组织 10–20 名学生开展真实试点。
- [ ] 完成实验组/对照组划分、前测、后测和问卷。
- [ ] 确认马其瑞、孙雨瑶、居欣月的专业、年级和分工。
- [ ] 完成 AIC 八大部分技术方案最终稿。

## P1 强烈建议

- [ ] 将创新点整理为三大新模式：AI 个性化教学、AI 虚拟实验实训、跨学科辅导。
- [ ] 补充经济可行性分析。
- [ ] 补充计算机科学与技术 × 电子信息工程的学科界定。
- [ ] 补充实施计划、时间线和资源保障。
- [ ] 补充 15–20 篇参考文献。
- [ ] 按比赛要求调整 PPT 页数和内容。

## P2 增强项

- [ ] 将实验实训需求深度分析写入正式材料。
- [ ] 补充传统 LMS 与 AI 学习平台对比，论证 AI 赋能必要性。
- [ ] 录制 5–8 分钟演示视频，覆盖跨学科路径、故障实验和教师报告。
- [ ] 补充教育数字化、AI 趋势和三阶段推广展望。

## 文档提交前检查

- [ ] 项目名称、团队名称和成员信息在所有材料中一致。
- [ ] 三门课程名称和学科定位一致。
- [ ] 算法名称、接口和验证结果与代码一致。
- [ ] 不把未配置的 Provider 写成已实际调用。
- [ ] 不把计划中的真实试点写成已完成试点。
- [ ] 技术方案中的功能名称与当前路由/页面一致。
- [ ] 测试报告记录真实命令、日期和结果。
- [ ] PPT、演示视频、源码和文档版本统一。
