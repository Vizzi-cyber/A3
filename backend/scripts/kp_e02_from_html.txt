## 第2章 电阻电路的等效变换

### 2.1 电路的等效变换

**【明确】**等效变换不仅仅是一种电路的分析手段，更应该被确立为一种贯穿电路学习始终的核心思想理念。

> **提示：**

#### 【水木杨仔语录】

"分析任何一个电路之前，首先问问自己，这个电路能否进行化简？"

**等效变换的条件：**两个电路，若具有相同的端口VCR（伏安特性），则它们对外电路是等效的。

**等效变换的目的：**在不影响分析结果的前提下，简化电路结构，从而简化分析计算。

**等效变换的要点：**

- 等效变换前后，电路的外部特性（伏安关系）保持不变

- 等效变换只适用于线性电路

- 等效变换的目的是简化电路分析

- 等效变换只是对外电路等效，对内部不一定等效

### 2.2 电阻的串联和并联

#### 电阻串联

**定义：**若干个电阻依次连接，流过每个电阻的电流都相同。

$R_{eq} = R_1 + R_2 + \cdots + R_n$

**串联分压：**$u_k = \frac{R_k}{R_{eq}} u$，各电阻分得的电压与其电阻值成正比。

#### 电阻并联

**定义：**若干个电阻并列连接，每个电阻两端的电压都相同。

$\frac{1}{R_{eq}} = \frac{1}{R_1} + \frac{1}{R_2} + \cdots + \frac{1}{R_n}$

**并联分流：**$i_k = \frac{G_k}{G_{eq}} i$，各电阻分得的电流与其电导值成正比，与电阻值成反比。

#### 两个电阻的并联

$R_{eq} = \frac{R_1 R_2}{R_1 + R_2}$

#### 特殊阻值电阻的并联

- **2倍电阻并联：**$R || 2R = \frac{2R}{3}$

- **3倍电阻并联：**$R || 3R = \frac{3R}{4}$

- **n个相同电阻并联：**$R || R || \cdots || R = \frac{R}{n}$

#### 对偶性

电路中的对偶思想：电压与电流对偶、电阻与电导对偶、串联与并联对偶、KCL与KVL对偶。

- **电阻串联分压：**$u_k = \frac{R_k}{R_{eq}} u$

- **电导并联分流：**$i_k = \frac{G_k}{G_{eq}} i$

#### 电桥结构电路

**基本形式：**电桥结构包含两个桥臂与一个桥路，桥路两端点位于两个对角线中间。

**特点：**电桥是一种复杂的结构，直接化解难度较大，因此一般通过适当的等效变换来巧妙化解。

**平衡电桥：**当电桥满足等电位条件时，称为平衡电桥。平衡电桥的桥路可以视为无源，其等效电阻为0。

> **注意：**

#### 【明确】

对于平衡电桥结构，若桥路无源，则桥路无响应，既可开路、也可短路，对电路无影响！

实际考试中，平衡电桥的结构可能较为"隐晦"，需要仔细识别。

### 2.3 电阻的Y-△等效变换

**星形（Y）结构：**由一公共节点向外引出三条支路，每条支路连接一电阻元件与外部相连接。

**三角形（△）结构：**三个电阻接成三角形，三角形每个顶点向外引出一根导线与外部相连接。

**Y→△变换公式：**

$R_{12} = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_3}$

$R_{23} = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_1}$

$R_{31} = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_2}$

**△→Y变换公式：**

$R_1 = \frac{R_{12} R_{31}}{R_{12} + R_{23} + R_{31}}$

$R_2 = \frac{R_{12} R_{23}}{R_{12} + R_{23} + R_{31}}$

$R_3 = \frac{R_{23} R_{31}}{R_{12} + R_{23} + R_{31}}$

**三支路电阻相等时：**

$R_{\triangle} = 3R_Y$ 或 $R_Y = \frac{R_{\triangle}}{3}$

### 2.4 电压源、电流源的串联和并联

#### 电压源的串联等效

若干个电压源串联，对外可等效为一个电压源。

$U_S = U_{S1} + U_{S2} + \cdots$（极性相同取"+"，极性相反取"-"）

#### 电压源的并联等效

相同电压的电压源可以并联，对外仍等效为一个电压源。不同电压的电压源不允许并联。

#### 电流源的串联等效

相同电流的电流源可以串联，对外仍等效为一个电流源。不同电流的电流源不允许串联。

#### 电流源的并联等效

若干个电流源并联，对外可等效为一个电流源。

$I_S = I_{S1} + I_{S2} + \cdots$

> **重要：**

#### 【与电压源并联/与电流源串联元件的处理】

【1】与电压源并联的部分，对外不起作用，可等效去掉

【2】但等效去掉后，会影响电压源电流（电流源电压）！

【3】与电流源串联的部分，对外不起作用，可等效去掉

【4】但等效去掉后，会影响电流源电压（电压源电流）！

【5】此方法可在不对外产生任何影响的前提下，将含电压源支路化为、含电流源支路化为

### 2.5 戴维宁-诺顿支路及其等效变换

**戴维宁典型支路：**一电压源与一电阻串联构成，其端口的VCR为一条不过原点的倾斜直线。

**诺顿典型支路：**一电流源与一电阻并联构成，其端口的VCR为一条不过原点的倾斜直线。

**戴维宁→诺顿变换：**

$I_S = \frac{U_S}{R}$（短路电流）

$R_{eq}$ 保持不变

**诺顿→戴维宁变换：**

$U_S = I_S \cdot R$（开路电压）

$R_{eq}$ 保持不变

> **注意：**

#### 【补充】

【1】对于实际电压源结构（实际电压源），其内阻值越小，VCR越接近理想电压源。当其内阻为0时，过渡到理想电压源。

【2】对于实际电流源结构（实际电流源），其内阻值越大，VCR越接近理想电流源。当其内阻为∞时，过渡到理想电流源。
