# 电阻电路的一般分析

## 一、支路电流法

**基本思想：** 以各支路电流为未知量，直接应用KCL和KVL列方程求解。

**方程数目：** 对于有 $n$ 个节点、$b$ 条支路的电路，需列 $b$ 个独立方程。
- KCL方程：$n-1$ 个
- KVL方程：$b-(n-1)$ 个

**解题步骤：**
1. 标注各支路电流的参考方向
2. 对 $n-1$ 个节点列KCL方程
3. 选取 $b-(n-1)$ 个独立回路，列KVL方程
4. 联立求解

**例题：** 如图电路，$U_S=12V$，$R_1=2\Omega$，$R_2=4\Omega$，$R_3=6\Omega$，用支路电流法求各支路电流。

- 回路1的KVL：$U_S = I_1 R_1 + I_3 R_3$
- 回路2的KVL：$I_3 R_3 = I_2 R_2$

代入数据：
- $I_1 = I_2 + I_3$
- $12 = 2I_1 + 6I_3$
- $6I_3 = 4I_2$

解得：$I_1 = 3A$，$I_2 = 1.8A$，$I_3 = 1.2A$

## 二、网孔电流法

**基本思想：** 以各网孔电流为未知量，应用KVL列方程求解。只适用于**平面电路**。

**方程数目：** 等于网孔数 $m = b-(n-1)$。

**自电阻与互电阻：**
- **自电阻：** 第 $k$ 个网孔所有电阻之和，恒为正
- **互电阻：** 两个网孔公共支路的电阻，两网孔电流方向相同时取正，相反时取负

**标准形式：**
$$R_{11}I_{m1} + R_{12}I_{m2} + \cdots + R_{1m}I_{mm} = U_{S11}$$
$$R_{21}I_{m1} + R_{22}I_{m2} + \cdots + R_{2m}I_{mm} = U_{S22}$$
$$dots$$

其中 $U_{Skk}$ 为第 $k$ 个网孔中电压源的代数和（电压升为正）。

**例题：** $U_{S1}=10V$，$U_{S2}=6V$，$R_1=2\Omega$，$R_2=3\Omega$，$R_3=4\Omega$，用网孔电流法求解。

**解：** 设两个网孔电流 $I_{m1}$、$I_{m2}$（均顺时针）。
- 网孔1：$(R_1+R_3)I_{m1} - R_3 I_{m2} = U_{S1}$
- 网孔2：$-R_3 I_{m1} + (R_2+R_3)I_{m2} = -U_{S2}$

代入数据：
- $6I_{m1} - 4I_{m2} = 10$
- $-4I_{m1} + 7I_{m2} = -6$

解得：$I_{m1} = 2A$，$I_{m2} = 0A$

## 三、节点电压法

**基本思想：** 以节点电压为未知量，应用KCL列方程求解。适用于**所有电路**。

**自电导与互电导：**
- **自电导：** 连接到该节点所有电导之和，恒为正
- **互电导：** 两节点间电导之和，恒为负

**标准形式（以参考节点为0）：**
$$G_{11}U_{n1} + G_{12}U_{n2} + \cdots + G_{1n}U_{nn} = I_{S11}$$
$$G_{21}U_{n1} + G_{22}U_{n2} + \cdots + G_{2n}U_{nn} = I_{S22}$$
$$dots$$

其中 $I_{Skk}$ 为流入第 $k$ 个节点的电流源电流的代数和。

**例题：** $U_S=12V$，$R_1=2\Omega$，$R_2=3\Omega$，$R_3=6\Omega$，用电压源串联电阻模型转换为电流源并联电阻模型后，用节点电压法求解。

**解：** 将电压源 $U_S$ 串联 $R_1$ 转换为电流源 $I_S=6A$ 并联 $R_1$。
- 节点电压方程：$(G_1+G_2+G_3)U_n = I_S$
- $(1/2+1/3+1/6)U_n = 6$
- $1 	imes U_n = 6$
- $U_n = 6V$

各支路电流：
- $I_1 = (U_S-U_n)/R_1 = (12-6)/2 = 3A$
- $I_2 = U_n/R_2 = 6/3 = 2A$
- $I_3 = U_n/R_3 = 6/6 = 1A$

## 四、回路电流法

**基本思想：** 选择一组独立回路，以回路电流为未知量列KVL方程。是网孔电流法的推广。

**与网孔电流法的区别：**
- 网孔电流法：只能用于平面电路，网孔数等于独立回路数
- 回路电流法：可用于非平面电路，回路选择更灵活

**选择独立回路的方法：**
- 平面电路：选网孔作为独立回路
- 非平面电路：用树支和连支确定独立回路

**解题步骤：**
1. 选择一组独立回路
2. 设定各回路电流参考方向
3. 列写KVL方程
4. 联立求解

## 五、电路的对偶性

**对偶元素：**
- 电压 ↔ 电流
- 电阻 ↔ 电导
- 串联 ↔ 并联
- KCL ↔ KVL
- 节点 ↔ 网孔
- 短路 ↔ 开路

**对偶原理：** 若将一个电路中的所有元素替换为其对偶元素，得到的对偶电路的方程形式与原电路相同。
