# 电阻电路的等效变换

## 一、等效变换的概念

**等效变换的条件：** 两个电路，若具有相同的端口VCR（伏安特性），则它们对外电路是等效的。

**等效变换的目的：** 在不影响分析结果的前提下，简化电路结构，从而简化分析计算。

**等效变换的要点：**
- 等效变换前后，电路的外部特性（伏安关系）保持不变
- 等效变换只适用于线性电路
- 等效变换只是对外电路等效，对内部不一定等效

**核心思想：** 分析任何电路之前，首先问自己：这个电路能否进行化简？

## 二、电阻的串联和并联

### 电阻串联
**定义：** 若干个电阻依次连接，流过每个电阻的电流都相同。

**等效电阻：**
$$R_{eq} = R_1 + R_2 + \cdots + R_n$$

**串联分压：**
$$u_k = rac{R_k}{R_{eq}} u$$

### 电阻并联
**定义：** 若干个电阻并列连接，每个电阻两端的电压都相同。

**等效电阻：**
$$rac{1}{R_{eq}} = rac{1}{R_1} + rac{1}{R_2} + \cdots + rac{1}{R_n}$$

**并联分流：**
$$i_k = rac{G_k}{G_{eq}} i$$

**两个电阻并联：**
$$R_{eq} = rac{R_1 R_2}{R_1 + R_2}$$

**特殊阻值并联：**
- 2倍电阻并联：$R \| 2R = rac{2R}{3}$
- 3倍电阻并联：$R \| 3R = rac{3R}{4}$
- n个相同电阻并联：$R \| R \| \cdots \| R = rac{R}{n}$

### 对偶性
电路中的对偶思想：电压与电流对偶、电阻与电导对偶、串联与并联对偶、KCL与KVL对偶。

### 电桥结构电路
**基本形式：** 电桥结构包含两个桥臂与一个桥路，桥路两端点位于两个对角线中间。

**平衡电桥：** 当桥路满足等电位条件时，桥路无响应，既可开路、也可短路，对电路无影响。

## 三、Y-Δ等效变换

### Y形网络（星形网络）
三个电阻连接到一个公共节点。

### Δ形网络（三角形网络）
三个电阻首尾相连形成三角形。

### 变换公式
**Y → Δ：**
$$R_{12} = rac{R_1R_2 + R_2R_3 + R_3R_1}{R_3}$$

**Δ → Y：**
$$R_1 = rac{R_{12}R_{13}}{R_{12} + R_{23} + R_{13}}$$

## 四、电压源、电流源的串联和并联

### 电压源串联
$$U_S = U_{S1} + U_{S2} + \cdots$$（极性相同取"+"，极性相反取"-"）

### 电压源并联
相同电压的电压源可以并联，对外仍等效为一个电压源。不同电压的电压源不允许并联。

### 电流源串联
相同电流的电流源可以串联，对外仍等效为一个电流源。不同电流的电流源不允许串联。

### 电流源并联
$$I_S = I_{S1} + I_{S2} + \cdots$$

**与电压源并联/与电流源串联元件的处理：**
- 与电压源并联的部分，对外不起作用，可等效去掉
- 与电流源串联的部分，对外不起作用，可等效去掉

## 五、戴维宁-诺顿支路及其等效变换

**戴维宁典型支路：** 一电压源与一电阻串联构成，其端口VCR为：$u = U_S + Ri$

**诺顿典型支路：** 一电流源与一电阻并联构成，其端口VCR为：$u = Ri - RI_S$

**戴维宁→诺顿变换：** $I_S = rac{U_S}{R}$（短路电流），$R_{eq}$ 保持不变
