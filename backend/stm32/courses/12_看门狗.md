# 第十二章：看门狗

## 学习目标

完成本章后，你将能够：
- 理解看门狗作用
- 配置独立看门狗和窗口看门狗

---

## 12.1 独立看门狗(IWDG)

### 知识点
```
时钟: LSI (40KHz)
超时: 可配置 (0.1ms ~ 26.2s)
复位: 超时未喂狗则复位
```

### 代码
```c
#include "stm32f10x.h"

void IWDG_Init(void)
{
    IWDG_WriteAccessCmd(IWDG_WriteAccess_Enable);
    
    IWDG_SetPrescaler(IWDG_Prescaler_64);
    IWDG_SetReload(625);  // 1s超时
    
    IWDG_ReloadCounter();
    IWDG_Enable();
}

int main(void)
{
    IWDG_Init();
    
    while (1)
    {
        IWDG_ReloadCounter();  // 喂狗
        
        for (volatile int i = 0; i < 500000; i++);  // 延时约500ms
    }
}
```

## 12.2 窗口看门狗(WWDG)

### 知识点
```
时钟: APB1
窗口: 可配置上限
特点: 必须在窗口内喂狗
```

### 代码
```c
#include "stm32f10x.h"

void WWDG_Init(void)
{
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_WWDG, ENABLE);
    
    WWDG_SetPrescaler(WWDG_Prescaler_8);
    WWDG_SetWindowValue(0x50);  // 窗口值
    WWDG_Enable(0x7F);          // 启动并设置计数器值
}

int main(void)
{
    WWDG_Init();
    
    while (1)
    {
        // 在窗口内喂狗
        WWDG_SetCounter(0x7F);
    }
}

// WWDG中断（用于提前喂狗）
void WWDG_IRQHandler(void)
{
    WWDG_SetCounter(0x7F);
    WWDG_ClearFlag();
}
```
