## 1.1 工程模板创建

### 实验目的
学会使用 Keil MDK 创建 STM32 工程，理解工程文件结构。

### 知识点
- STM32 启动文件（startup_stm32f10x_md.s）
- 系统时钟配置（72MHz）
- 外设库文件包含

### 工程结构
```
Project/
├── Start/                    # 启动文件
│   ├── startup_stm32f10x_md.s
│   └── system_stm32f10x.c
├── Library/                  # 标准外设库
│   ├── inc/
│   └── src/
├── User/                     # 用户代码
│   ├── main.c
│   └── stm32f10x_conf.h
└── Project.uvprojx           # Keil工程文件
```

### Keil配置步骤
1. 新建工程，选择芯片 STM32F103C8
2. 添加启动文件 `startup_stm32f10x_md.s`
3. 添加外设库文件（根据需要）
4. 配置 C/C++ 宏定义：`STM32F10X_MD, USE_STDPERIPH_DRIVER`

### 代码模板
```c
#include "stm32f10x.h"

int main(void)
{
    /* 系统初始化已完成（在SystemInit中） */
    
    while (1)
    {
        
    }
}
```

## 1.2 GPIO输出 - LED闪烁

### 实验目的
掌握 GPIO 输出配置，实现 LED 闪烁效果。

### 硬件连接
```
STM32          LED
PA0 ────────── LED正极 ──── 220Ω ──── GND
```

**接线图参考**: `1-1 接线图/3-1 LED闪烁.jpg`

### 知识点详解

#### GPIO模式
| 模式 | 说明 | 适用场景 |
|------|------|----------|
| 推挽输出 | 可输出高/低电平 | LED驱动、蜂鸣器 |
| 开漏输出 | 只能输出低电平 | I2C总线 |
| 浮空输入 | 无上下拉 | 外部信号输入 |
| 上拉输入 | 内部上拉 | 按键检测 |
| 下拉输入 | 内部下拉 | 按键检测 |

#### 时钟使能
STM32 外设默认不工作，必须先使能时钟：
```c
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);
```

### 完整代码
```c
#include "stm32f10x.h"
#include "Delay.h"

int main(void)
{
    /* 1. 开启GPIOA时钟 */
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);
    
    /* 2. 配置PA0为推挽输出 */
    GPIO_InitTypeDef GPIO_InitStructure;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;    // 推挽输出
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;           // PA0
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;   // 50MHz
    GPIO_Init(GPIOA, &GPIO_InitStructure);
    
    /* 3. 主循环 - LED闪烁 */
    while (1)
    {
        GPIO_ResetBits(GPIOA, GPIO_Pin_0);  // PA0输出低电平（LED亮）
        Delay_ms(500);
        GPIO_SetBits(GPIOA, GPIO_Pin_0);    // PA0输出高电平（LED灭）
        Delay_ms(500);
    }
}
```

### 三种控制电平的方法
```c
// 方法1：使用ResetBits/SetBits
GPIO_ResetBits(GPIOA, GPIO_Pin_0);   // 低电平
GPIO_SetBits(GPIOA, GPIO_Pin_0);     // 高电平

// 方法2：使用WriteBit
GPIO_WriteBit(GPIOA, GPIO_Pin_0, Bit_RESET);  // 低电平
GPIO_WriteBit(GPIOA, GPIO_Pin_0, Bit_SET);    // 高电平

// 方法3：使用GPIO_Write
GPIO_Write(GPIOA, 0x0001);  // PA0输出高，其他引脚输出低
```

### 实验现象
LED 以 1Hz 频率闪烁（亮500ms，灭500ms）。

## 1.3 GPIO输出 - LED流水灯

### 实验目的
掌握批量 GPIO 操作，实现流水灯效果。

### 硬件连接
```
STM32          LED
PA0 ────────── LED1正极 ──── 220Ω ──── GND
PA1 ────────── LED2正极 ──── 220Ω ──── GND
PA2 ────────── LED3正极 ──── 220Ω ──── GND
PA3 ────────── LED4正极 ──── 220Ω ──── GND
PA4 ────────── LED5正极 ──── 220Ω ──── GND
PA5 ────────── LED6正极 ──── 220Ω ──── GND
PA6 ────────── LED7正极 ──── 220Ω ──── GND
PA7 ────────── LED8正极 ──── 220Ω ──── GND
```

**接线图参考**: `1-1 接线图/3-2 LED流水灯.jpg`

### 完整代码
```c
#include "stm32f10x.h"
#include "Delay.h"

int main(void)
{
    /* 开启GPIOA时钟 */
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);
    
    /* 配置PA0~PA7为推挽输出 */
    GPIO_InitTypeDef GPIO_InitStructure;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0 | GPIO_Pin_1 | GPIO_Pin_2 | GPIO_Pin_3 |
                                  GPIO_Pin_4 | GPIO_Pin_5 | GPIO_Pin_6 | GPIO_Pin_7;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOA, &GPIO_InitStructure);
    
    while (1)
    {
        /* 流水灯效果 */
        for (int i = 0; i < 8; i++)
        {
            GPIO_Write(GPIOA, ~(0x01 << i));  // 低电平点亮，取反
            Delay_ms(200);
        }
    }
}
```

### 实验现象
8个LED依次点亮，形成流水灯效果。

## 1.4 GPIO输出 - 蜂鸣器

### 实验目的
掌握蜂鸣器驱动方法。

### 硬件连接
```
STM32          蜂鸣器
PA2 ────────── 蜂鸣器正极
GND ────────── 蜂鸣器负极
```

**接线图参考**: `1-1 接线图/3-3 蜂鸣器.jpg`

### 知识点
- **有源蜂鸣器**：内部有振荡电路，给电即响
- **无源蜂鸣器**：需要PWM信号驱动

### 完整代码
```c
#include "stm32f10x.h"
#include "Delay.h"

int main(void)
{
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);
    
    GPIO_InitTypeDef GPIO_InitStructure;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_2;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOA, &GPIO_InitStructure);
    
    while (1)
    {
        GPIO_SetBits(GPIOA, GPIO_Pin_2);     // 蜂鸣器响
        Delay_ms(500);
        GPIO_ResetBits(GPIOA, GPIO_Pin_2);   // 蜂鸣器停
        Delay_ms(500);
    }
}
```

## 1.5 GPIO输入 - 按键控制LED

### 实验目的
掌握 GPIO 输入配置，实现按键控制 LED。

### 硬件连接
```
STM32          按键          LED
PA1 ────────── 按键 ──── GND
PA0 ────────── LED正极 ──── 220Ω ──── GND
```

**接线图参考**: `1-1 接线图/3-4 按键控制LED.jpg`

### 知识点：按键消抖
机械按键按下/释放时会产生抖动（5~20ms），需要消抖处理：
```c
// 简单延时消抖
if (GPIO_ReadInputDataBit(GPIOA, GPIO_Pin_1) == 0)  // 按下
{
    Delay_ms(20);  // 等待抖动消除
    if (GPIO_ReadInputDataBit(GPIOA, GPIO_Pin_1) == 0)  // 再次确认
    {
        // 确认按下，执行操作
    }
}
```

### 完整代码
```c
#include "stm32f10x.h"
#include "Delay.h"

int main(void)
{
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);
    
    /* PA0 - LED输出 */
    GPIO_InitTypeDef GPIO_InitStructure;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOA, &GPIO_InitStructure);
    
    /* PA1 - 按键输入（上拉） */
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU;   // 上拉输入
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_1;
    GPIO_Init(GPIOA, &GPIO_InitStructure);
    
    uint8_t ledState = 0;
    
    while (1)
    {
        if (GPIO_ReadInputDataBit(GPIOA, GPIO_Pin_1) == 0)  // 按下
        {
            Delay_ms(20);  // 消抖
            if (GPIO_ReadInputDataBit(GPIOA, GPIO_Pin_1) == 0)
            {
                ledState = !ledState;  // 切换状态
                if (ledState)
                    GPIO_SetBits(GPIOA, GPIO_Pin_0);     // LED亮
                else
                    GPIO_ResetBits(GPIOA, GPIO_Pin_0);   // LED灭
                
                while (GPIO_ReadInputDataBit(GPIOA, GPIO_Pin_1) == 0);  // 等待松开
            }
        }
    }
}
```

### 实验现象
按下按键切换 LED 亮灭状态。

## 1.6 GPIO综合 - 光敏传感器

### 实验目的
综合运用 GPIO 输入输出，实现传感器控制。

### 硬件连接
```
STM32          传感器          蜂鸣器
PA1 ────────── 光敏传感器DO ──── VCC/GND
PA2 ────────── 蜂鸣器正极 ──── GND
```

**接线图参考**: `1-1 接线图/3-5 光敏传感器控制蜂鸣器.jpg`

### 完整代码
```c
#include "stm32f10x.h"
#include "Delay.h"

int main(void)
{
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);
    
    /* PA2 - 蜂鸣器输出 */
    GPIO_InitTypeDef GPIO_InitStructure;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_2;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOA, &GPIO_InitStructure);
    
    /* PA1 - 传感器输入 */
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU;   // 上拉输入
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_1;
    GPIO_Init(GPIOA, &GPIO_InitStructure);
    
    while (1)
    {
        if (GPIO_ReadInputDataBit(GPIOA, GPIO_Pin_1) == 0)  // 光照不足
        {
            GPIO_SetBits(GPIOA, GPIO_Pin_2);     // 蜂鸣器响
        }
        else
        {
            GPIO_ResetBits(GPIOA, GPIO_Pin_2);   // 蜂鸣器停
        }
    }
}
```
