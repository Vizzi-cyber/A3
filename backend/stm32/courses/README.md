# STM32 嵌入式开发完整课程

## 课程简介

本课程基于 STM32F103C8T6 最小系统板，从零基础到高级外设，系统学习嵌入式开发。课程包含 40+ 个实验项目，每个实验都配有：
- 详细的接线图
- 完整的注释代码
- 原理讲解
- 实验指导

## 开发环境

- **芯片**: STM32F103C8T6 (Cortex-M3, 72MHz, 64KB Flash, 20KB RAM)
- **IDE**: Keil MDK-ARM 5
- **固件库**: STM32 标准外设库 (SPL)
- **调试器**: ST-Link V2 / J-Link

### 常用接线对照

| 外设 | STM32引脚 | 说明 |
|------|-----------|------|
| LED | PA0 | 推挽输出 |
| 按键 | PA1 | 上拉输入 |
| 蜂鸣器 | PA2 | 推挽输出 |
| OLED(SCL) | PB10 | I2C时钟 |
| OLED(SDA) | PB11 | I2C数据 |
| MPU6050(SCL) | PB10 | I2C时钟 |
| MPU6050(SDA) | PB11 | I2C数据 |
| 串口TX | PA9 | USART1_TX |
| 串口RX | PA10 | USART1_RX |
| 舵机 | PA0 | TIM2_CH1 |
| 电机 | PA1 | TIM2_CH2 |

## 代码规范

### 命名规范
- 函数：`外设_Init()`, `外设_功能()`
- 变量：小驼峰 `newValue`
- 常量：全大写 `MAX_VALUE`

### 代码结构
```c
#include "stm32f10x.h"
#include "模块.h"

int main(void)
{
    /* 模块初始化 */
    模块_Init();
    
    while (1)
    {
        /* 主循环逻辑 */
    }
}
```
