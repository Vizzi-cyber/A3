# LearnLab 现场演示预案（2026-11-25）

## 一、演示目标

用 3–6 分钟证明三件事：**系统真的在运行**、**算法真的在算**、**跨课程真的通了**。

## 三、演示前 30 分钟检查清单

- [ ] 用比赛现场网络打开线上站点，确认登录页正常
- [ ] 学生账号登录一次，确认首页数据非空白
- [ ] 教师账号登录一次，确认学情页有数据
- [ ] 打开"电路仿真"页，跑一次 RC 充电，确认波形出现
- [ ] 打开"错误诊断"页，提交一段错误代码，确认返回分层诊断
- [ ] 浏览器缩放设为 100%，关闭无关标签页与通知
- [ ] 准备离线兜底：本地截图包 + 3 分钟预录屏 + 本地启动命令
- [ ] 手机开热点作为第二网络（电脑保持同一浏览器会话）

## 四、三条演示路径

### 路径 A：完整版（约 6 分钟，评委说"演示一下"时用）

1. **学生首页**：展示今日路径、待复习知识点、掌握度。说明"路径是按掌握度算的，不是固定课表"。
2. **答题 / 每日练习**：答一题，展示即时反馈与解析；强调解析由五层算法 + 大模型共同生成。
3. **学习路径**：打开路径页，指出跨课程节点（C 语言 → 电路 → STM32），说明 ADPP 的排序依据。
4. **电路仿真**：搭一个 RC 电路，改电阻值，观察波形变化；说明求解在浏览器内完成。
5. **故障诊断**：注入"断路"故障，读出异常电压，提交判断，展示 AI 讲解。
6. **教师端**：切到教师账号，打开班级学情，指出掌握度分布与预警名单。

### 路径 B：精简版（约 3 分钟，时间被压缩时用）

学生首页 → 电路仿真（RC 充电 + 故障诊断）→ 教师端学情一页。三处各停留 40 秒，其余口头带过。

### 路径 C：离线兜底（网络或站点不可用时用）

1. 播放 3 分钟预录屏（`04-作品视频` 的节选，另存本地）。
2. 打开本地截图包，按"首页 → 路径 → 仿真 → 诊断 → 教师端"顺序讲。
3. 说明：仿真求解在浏览器端完成，本地启动后不依赖外网；线上站点仅作为承载。

## 五、故障应对表

| 故障 | 现场动作 | 话术 |
|---|---|---|
| 页面打不开 | 换备用域名 → 换热点 → 转路径 C | "线上环境受现场网络影响，我们有本地兜底，先看预录屏。" |
| 大模型接口超时 | 等待 8 秒；仍失败则改用"规则诊断"入口 | "AI 接口有自动降级，诊断结论仍由本地规则给出。" |
| 登录失败 | 改用"体验账号"快捷入口 | "评审入口提供免登录体验账号。" |
| 数据空白 | 刷新一次；仍空白则用教师端演示数据 | "演示库是种子数据，教师端数据更完整。" |
| 投影分辨率异常 | 浏览器缩放 100%，全屏 F11 | — |

## 六、演示时的三句关键话术

1. "这条路径不是我点出来的，是系统按掌握度和先修关系算出来的。"
2. "这个电路没有连后端，求解就在当前浏览器里完成。"
3. "诊断结论会回写到学生画像，下一次路径会变。"
