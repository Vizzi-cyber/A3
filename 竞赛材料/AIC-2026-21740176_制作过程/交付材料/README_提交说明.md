# LearnLab 参赛材料提交对照（2026 AIC · 赛题5 AI+学科交叉）

> 团队：一起搞事情 ｜ 参赛编号：AIC-2026-21740176 ｜ 作品：LearnLab 跨学科智能学习平台

## 一、报名系统字段 ↔ 本目录文件对照

报名系统共 7 个提交项，逐项对应关系如下。「表单直传」列的文件可直接上传到报名系统；作品材料文件夹按赛题和省赛规则组织后上传至网盘。

| # | 报名系统字段 | 格式要求 | 对应文件 |
|---|---|---|---|
| 1 | 参赛作品名称 | ≤20 字 | `LearnLab 跨学科智能学习平台` |
| 2 | 参赛作品简介 | ≤300 字 | `参赛作品简介_300字.txt` |
| 3 | 文档类文件（技术报告/技术方案） | 仅 PDF，≤10MB | `1_技术方案.pdf` |
| 4 | PPT 类文件 | 统一 PDF | `_待放入_PPT与视频/` 中的答辩 PPT PDF |
| 5 | 视频类文件 | MP4，3–5 分钟，≤300MB | `_待放入_PPT与视频/` 中的演示视频 |
| 6 | 佐证材料文件 | 仅 PDF | `4_佐证材料 .pdf` |
| 7 | 作品材料文件夹百度网盘链接 | 永久有效并设置提取码 | `网盘提交/` |

另需单独提交：`5_参赛承诺书_已签字.pdf`（按报名系统要求上传）。

第 4、5 项的文件命名规范与其余材料一致，详见 `_待放入_PPT与视频/README.txt`。

### 江苏赛区附加要求（依附件3《江苏赛区作品提交流程》）

江苏省赛在报名系统字段之外，另有两项硬性要求：

| 要求 | 说明 |
|---|---|
| **答辩汇报 PPT 视频** | MP4，分辨率 ≥1080p，时长 ≤6 分钟（**必交**，与演示视频不是同一个） |
| **参赛选手检录照片** | 证件信息须与视频中参赛团队**一致，不一致视为作弊**（第 9 条） |

网盘文件夹命名也以江苏赛区要求为准（见下方「三、网盘上传」）。

## 二、材料内容说明

- **1_技术方案.pdf**：完整技术方案，包含项目概述、需求分析、解决方案、可行性、实施方案、应用效果与附录。
- **4_佐证材料 .pdf**：测试验证数据、算法评估、系统截图、试点材料和原创性说明的合并文档。
- **网盘源代码.zip**：评审运行所需源码、演示数据库、测试脚本和运行说明。

## 四、提交前自查清单

- [ ] 作品名称不超过 20 字，作品简介不超过 300 字。
- [ ] 技术方案、佐证材料和答辩 PPT均为 PDF，并可正常打开。
- [ ] 演示视频为 MP4，时长符合赛区要求且文件大小不超过 300MB。
- [ ] 答辩汇报视频与作品演示视频分别准备，内容与提交材料一致。
- [ ] 网盘外层、内层目录和文件名符合规则。
- [ ] 网盘分享链接设置为长期有效并已生成提取码。
- [ ] 对外材料不包含学校名称、校徽或指导教师信息。

## 六、重新生成方法

```bash
# 技术方案（改 main.tex 后）
cd 交付材料/02_技术方案/latex && xelatex main.tex && xelatex main.tex

# 佐证材料（改 zz.tex 后）
cd 交付材料/04_佐证材料_latex && xelatex zz.tex && xelatex zz.tex

# 源码包
python make_source_package.py

# 功能说明 / 功能验证清单 / 运行说明（Markdown → PDF）
python scripts/md_to_pdf.py 文档信息/09_功能说明_评审版.md <输出路径>
python scripts/md_to_pdf.py 文档信息/10_功能验证清单.md <输出路径>
python scripts/md_to_pdf.py 文档信息/08_源码评审运行说明.md <输出路径>

# 口播稿 Word
python scripts/gen_koubo_docx.py
```

## 七、提交前自动审计

改动材料后，运行审计脚本做最终把关（提交前必跑）：

```bash
python scripts/audit_submission.py
```

脚本检查五项：内部信息残留、关键数字在各文档间的一致性、
交叉引用是否指向真实存在的文件、命名规范、公平性（校名/指导教师）。

全部通过时会输出「结论：全部通过 ✅」。
